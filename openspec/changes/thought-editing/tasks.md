## 1. Backend

- [ ] 1.1 Move confirm's category check into `check_category(session, user, value, *, keep=None)` in `categories.py` from design decision 2, and call it from confirm. Check with pytest that the existing confirm tests pass unchanged, and that `check_category` accepts a fixed kind, an added category, empty as none, and `keep` for a removed category, and refuses any other name with `validation_error` naming `category`
- [ ] 1.2 Add `PATCH /api/thoughts/{id}` from design decisions 1 to 3. Check with pytest that it changes each of title, summary, tags, and category alone; that a missing field is kept and `"category": null` clears it; that the answer has the `GET` shape with the same `origin`; that `updated_at` grows on a change and stays on an empty body; that an empty title, a title over 200 characters, a bad tag, a foreign category, and `raw_text` each give 422 naming the field with the thought unchanged; that a removed category the thought has is kept on a title-only edit; that another user's thought and a missing one both give 404 `not_found` with the other user's thought unchanged; and that with the embedding provider unreachable the edit answers 200 and a word search finds the new summary
- [ ] 1.3 Check the embedding calls of `PATCH` with pytest and a counting fake provider: a title or summary edit makes one call for all pieces, a tags-only edit one call for the head piece, and a category-only edit or an empty body none; and after a summary edit a search for the old summary no longer finds the thought by it
- [ ] 1.4 Add `DELETE /api/thoughts/{id}` from design decision 1. Check with pytest that it answers 204, that `GET` then gives 404, that a search for its title no longer returns it, that its proposal and conversation stay with the part's `thought_id` unchanged, and that another user's thought and a missing one both give 404 `not_found` with the other user's thought still there
- [ ] 1.5 Add `saved_title` and `deleted` to `ProposalPart` in the messages answer, `OfferedProposal`, and the proposal stream event, from design decision 4. Check with pytest that a saved part shows the thought's current title after a `PATCH`, that it shows `deleted: true` and a null title after a `DELETE`, that an unsaved part has both empty, that a proposal whose only thought was deleted is not offered again to file, and that the messages endpoint's query count does not grow with the number of saved parts
